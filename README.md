# AI-Agent

Minimal full-stack scaffold for an AI-Agent application.

## Structure

- `frontend/` contains the Vite React app.
- `backend/` contains the FastAPI app.
- `docs/` is reserved for project documentation.
- `sample_data/` is reserved for future sample inputs.

## Run Frontend

```bash
cd frontend
npm run dev
```

## Run Backend

```bash
cd backend
uvicorn main:app --reload
```
